## Resumen del puesto

Durante mi contrato como desarrollador frontend en redOM8, participé de forma central en el desarrollo de una aplicación móvil. Mis responsabilidades incluyeron:

- Diseñar componentes en Figma, contribuyendo al desarrollo de la aplicación desde cero.
- Integrar componentes dinámicos con Dart/Flutter para mejorar las funciones y la experiencia de usuario.
- Desarrollar un sistema de backend para establecer una conexión fiable con el servidor alojado en Odoo, facilitando el intercambio de datos y la operación entre la interfaz y el servidor.

Esta experiencia me permitió aplicar mis habilidades de desarrollo frontend, Figma y diagramas de flujo, y profundizar mis conocimientos de Dart, Flutter y Odoo.
