# Prácticas de desarrollo frontend en StartupLab MX

- Sep 2022 – dic 2022 · 4 meses
- San Luis Potosí, México · Híbrido
- Prácticas profesionales

## Competencias

- Desarrollo frontend
- HTML
- Hojas de estilo en cascada (CSS)
- Bootstrap
- PHP
- MongoDB
- JavaScript
- Redacción de contenidos

## Resumen del puesto

Durante mis prácticas como desarrollador frontend en StartupLab MX, participé en el desarrollo web y la creación de contenido. Mis responsabilidades incluyeron:

- Colaborar en el desarrollo, mantenimiento y actualización de sistemas web y bases de datos para clientes con PHP, HTML, CSS, JavaScript, Bootstrap, MongoDB y, ocasionalmente, herramientas de bajo código.
- Redactar contenido web con atención a la claridad y la participación del usuario.
- Apoyar la dirección de un evento en vivo, gestionando a participantes y público en línea.

El puesto me permitió aplicar y fortalecer mis habilidades de desarrollo frontend, gestión de bases de datos y creación de contenido en distintos proyectos de StartupLab MX.
